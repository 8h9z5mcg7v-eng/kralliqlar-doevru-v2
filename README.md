# Krallıqlar Dövrü — Unity başlanğıc layihəsi

Orijinal orta əsr mobil strategiya oyunu üçün Unity 2022.3 LTS başlanğıcı.

## İlk səhnə
- Səhnə: Assets/Scenes/Kingdom.unity
- Başlanğıc skripti: Assets/Scripts/KingdomBootstrap.cs
- Divarlı qala-şəhər, dörd müdafiə qülləsi, darvaza, kral qalası, kazarma, tövlə, odunçu evi, daş karxanası, bazar, əkin sahələri və ağaclar.
- Mobil toxunuşla kameranı döndərmək və iki barmaqla yaxınlaşdırmaq.
- İlkin resurs HUD-u və prototip düymələri.

## Unity-də açmaq
1. Repozitoriyanı ZIP kimi endirib açın.
2. Unity Hub-da Add project from disk seçin.
3. Layihə qovluğunu Unity 2022.3 LTS ilə açın.
4. Assets/Scenes/Kingdom.unity səhnəsini açıb Play düyməsini basın.

## Vacib
Bu mərhələ lokal vizual prototipdir. Real multiplayer serveri, hesablar, serverdə təsdiqlənən döyüşlər, canlı dünya xəritəsi və ödənişlər hələ qoşulmayıb. Sonrakı mərhələlərdə server və verilənlər bazası qurulmalıdır. Clash of Kings-in müəllif hüquqları ilə qorunan kodu və aktivləri istifadə edilmir.
